# **App Name**: SynergyFlow ERP

## Core Features:

- Firebase User Authentication: Secure user login, logout, and protected route management using Firebase Authentication (email/password).
- Modular Dashboard Interface: Modern, responsive dashboard UI with a collapsible left sidebar providing structured navigation across HR, Sales, Quality, Production, Procurement, Supply Chain, Decay, Finance, and Settings modules.
- Firestore Data Management: CRUD operations (Create, Read, Update, Delete) for all module data stored in structured Firestore collections, including data tables, forms, search, filters, and pagination functionality for each module page.
- Role-Based Access Control (Basic): Implement basic user roles (e.g., Admin, User) to manage access permissions to specific modules or features.
- Real-time Dashboard Analytics: A central dashboard displaying key statistics and counts for critical data points across different ERP modules.
- AI Data Insight Tool: An AI tool that provides quick summaries or identifies potential trends and anomalies within the collected module data.
- Modular Firestore Data Models: Scalable data models in Firestore designed to reflect module structures and manage relationships between different collections (e.g., orders linked to customers, employees to departments).

## Style Guidelines:

- Light color scheme to ensure a clean, professional aesthetic for data readability.
- Primary color: A sophisticated, muted blue (#2B6CB0) to convey professionalism and trust.
- Background color: A very light, desaturated blue (#F6F8FB) to provide a clean and calming base for content.
- Accent color: A soft, contrasting cyan-green (#3CB2AC) to highlight interactive elements and important information.
- Body and headline font: 'Inter' (sans-serif) for its modern, objective, and highly readable design, ideal for data-intensive dashboards.
- Use a consistent set of clean, minimalist vector icons that clearly represent each module and action, ensuring a uniform visual language across the application.
- Implement a clear, well-structured layout with ample whitespace, ensuring data tables and forms are easy to navigate and comprehend, adhering to an 'admin panel' aesthetic.
